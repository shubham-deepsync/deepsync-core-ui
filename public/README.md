# Public Assets

This directory contains static assets that will be served by the application.

## Logo

Place your logo file here as `logo.svg` or `logo.png`. The application will automatically use it in the top navigation. If no logo is found, it will fall back to text "Deep Sync Cloud Platform".

Supported formats:
- SVG (recommended)
- PNG
- JPG

Preferred dimensions: 32px height, auto width
